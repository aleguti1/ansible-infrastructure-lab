## Monitoring Server Accounts and Databases
*This document provides a concise summary of different objects on `linux02`*

### Linux User Accounts
- `localadmin` Admin account
- `postgres` PostgreSQL system account
- `zabbix` Zabbix system account

### PostgreSQL Database Roles
- `postgres` Database admin
- `zabbix` Application database user

### Databases
- `zabbix` Monitoring database; owned by PostgreSQL role `zabbix`
